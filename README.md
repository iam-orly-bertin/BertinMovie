# 🎬 BertinMovie

**A web-based movie management and streaming platform.**

🌐 **Live:** [bertinmovie.freedev.app/film_web_dy/](https://bertinmovie.freedev.app/film_web_dy/)  
💻 **GitHub:** [github.com/iam-orly-bertin/BertinMovie](https://github.com/iam-orly-bertin/BertinMovie)

## ✨ Features

- 👤 User registration and authentication
- 🔑 Password recovery with OTP
- 🎬 Movie catalogue, search, filtering and sorting
- ▶️ Video streaming and view counter
- ❤️ Likes, comments and favourites
- 📜 Watch history
- 🤖 AI assistant and support chat
- 🔔 Notifications
- 🌙 Dark / light mode
- 🌍 French / English interface
- 📱 Responsive design
- 🔐 Administrator dashboard
- 👥 User and permission management
- 🎞️ Movie, video and category management
- 🗑️ Recycle bin and movie restoration
- 📦 Data archiving

## 🛠️ Technologies

- **PHP 8 / PDO**
- **MySQL / MariaDB**
- **HTML5 / CSS3**
- **Vanilla JavaScript**
- **PHPMailer**
- **Backblaze B2**
- **ImageKit**

## 🔒 Security

- Password hashing with `password_hash()`
- PDO prepared statements
- Session and role-based authentication
- Account lock after repeated failed logins
- OTP verification
- Private credentials excluded from the repository
